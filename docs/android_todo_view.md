# Android 1.0.9: compact day list and optional scheduled work logging

Tap the existing Timeline control while viewing a day to toggle its calendar and compact to-do list. The slashed Timeline icon means list mode. Returning from Inbox restores the selected day mode; the preference survives restart. List mode uses the already-loaded selected-day tasks, including scheduled, unscheduled and completed items. It retains editing, completion/reopening, Top Wins, habit/session metadata and timer actions. Rows use horizontal actions rather than tall stacked controls. Switching modes makes no API request; calendar dragging remains available in timeline mode.

Scheduled task timers no longer create compulsory log entries or open expiry forms automatically. Expiry still rings its completion sound, leaves the task unchanged, and does not submit actual work. Explicit Finish opens optional time entry; Ignore and Back discard an unsaved draft and return to the planner. Existing confirmed/retrying entries keep their retry identity. Old scheduled expiry drafts are relaxed locally on upgrade, with no task fetch or sequential popup queue. Unknown legacy drafts are also relaxed rather than trapping the user. Unscheduled manual timer expiry behavior remains unchanged. Completing a scheduled task with its checkbox does not require logging; manual Log time remains available.

Validation: 74 unit tests passed, Android lint passed, APK assembly passed. Isolated HTTPS emulator fixtures verified scheduled/unscheduled/completed rows, preference persistence, no day refetch on view toggles, scheduled expiry staying in MainActivity without a work submission, explicit optional form with Back and Ignore, ignored draft removal, and completion via the slim row without a work entry. The final slim dark layout was inspected. No production task was changed for these checks.
